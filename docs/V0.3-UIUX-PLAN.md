# SEOGEO v0.3 UI/UX 개선안

## 목표

사용자가 분석 결과를 단순히 읽는 데서 끝나지 않고 `분석 → 이해 → 행동 → 재검사` 흐름을 자연스럽게 완료하도록 만듭니다. v0.3에서는 점수 계산 로직과 기존 LocalStorage 데이터 구조를 유지하면서 화면 구조만 재설계합니다.

## 이번 버전에 반영한 핵심

- PinHome 레퍼런스를 응용한 청록색 내비게이션과 밝은 대시보드 캔버스
- SEO 기반 점수와 AI 인용 준비도를 대표 점수로 단순화
- 외부 라이브러리 없이 구현한 6개 영역 레이더 차트
- 낮은 점수부터 자동으로 정렬되는 카테고리 목록
- 긴급도와 예상 효과를 반영한 `지금 가장 먼저 할 일`
- 중복된 종합 리포트를 제거하고 수정 체크리스트를 `개선 액션`으로 통합
- 수정 완료 후 같은 URL을 바로 재검사하는 흐름
- 개발 로그 대신 4단계 분석 진행 화면
- 768px 이하에서 사이드바를 숨기고 모바일 하단 내비게이션 제공
- 키보드 포커스와 `prefers-reduced-motion` 접근성 대응

## 디자인 기준

- 브랜드 색상: 청록색 `#1ca69e`
- 정상: 초록색, 주의: 황색, 오류: 적색으로 상태 의미를 통일
- 큰 카드 16–20px, 작은 컨트롤 10–12px의 모서리 반경 사용
- 카드 중첩과 장식성 그림자를 최소화
- 핵심 설명은 기본 화면에 한두 줄만 노출하고 상세 정보는 기존 상세 화면에서 제공

## 다음 개선 후보

- 문제 카드의 현재 상태 → 목표 상태 → 수정 코드 → 검증 상태를 하나의 상태 모델로 저장
- 카테고리별 이전 점수 변화 표시
- 우리 회사/경쟁사/기타로 분석 기록 그룹화
- URL 기반 결과 딥링크와 요약 복사
- 결과 이미지/PDF 내보내기

공유 URL에 분석 데이터를 직접 넣는 방식은 개인정보와 URL 길이 문제를 먼저 검토한 뒤 적용합니다.
