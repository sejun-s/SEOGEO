# SEOGEO 개선 기획안

## 1. 현재 평가

SEOGEO는 SEO와 AI 검색 최적화를 한 화면에서 다룬다는 장점이 있습니다. 다만 초기 버전은 기능 수에 비해 검증 체계와 점수 설명이 부족해, 사용자가 결과를 얼마나 믿어야 하는지 판단하기 어렵습니다.

v0.2에서는 우선 프로덕션 빌드를 정상화하고 타입 안정성, 실행 문서, 분석 한계 안내를 보완합니다.

## 2. 핵심 개선 방향

### 신뢰할 수 있는 점수

- 각 평가 규칙에 출처, 규칙 버전, 측정값을 함께 표시
- 공식 요구사항과 자체 추천 기준을 화면에서 구분
- 종합 점수뿐 아니라 `검색 가능 여부`와 `AI 인용 준비도`를 별도 표시
- JavaScript 렌더링 미지원 등 측정 한계를 결과에 명시

### 결과를 행동으로 연결

- 문제를 `즉시 수정`, `중요`, `권장`, `참고`로 단순화
- 각 문제에 예상 효과, 수정 예제, 재검사 버튼 제공
- 수정 전후 점수 이력과 해결된 항목을 저장
- 보고서 PDF 및 공유 링크 제공

### 운영 안정성

- 점수 계산, URL 보안 검사, 응답 변환에 자동 테스트 추가
- GitHub Actions에서 lint, build, test 자동 실행
- API 키는 서버 환경 변수로만 사용하도록 운영 모드 강화
- 분석 요청 제한을 영속 저장소 기반으로 전환
- 실패 원인과 처리 시간을 운영 화면에서 확인

## 3. 우선순위

### P0 — 배포 기본기

- 프로덕션 빌드 오류 제거
- 타입 정의와 실제 응답 구조 통일
- README와 환경 변수 문서화
- CI에서 기본 품질 검사 자동화 (v0.2 적용)

완료 조건: 새 커밋마다 lint, build, test가 자동으로 통과해야 합니다.

### P1 — 분석 신뢰도

- 규칙별 단위 테스트
- 공식 출처와 자체 기준 표시
- 측정 신뢰도 및 수집 실패 상태 표시
- 동일 URL 재검사 결과 비교

완료 조건: 사용자가 점수의 근거와 한계를 화면에서 이해할 수 있어야 합니다.

### P2 — 실제 사용성

- 보고서 저장과 공유
- 프로젝트별 사이트 관리
- 경쟁사 비교 개선
- CMS별 수정 가이드

완료 조건: 분석 이후 수정, 재검사, 보고까지 한 흐름으로 처리할 수 있어야 합니다.

## 4. 권장 일정

- 1주차: 자동 테스트와 GitHub Actions
- 2주차: 점수 근거와 신뢰도 화면
- 3주차: 결과 저장, 재검사, 이력 비교
- 4주차: 보고서 공유와 운영 보안 강화

## 5. 성공 지표

- 프로덕션 빌드 성공률 100%
- 핵심 점수 규칙 테스트 커버리지 80% 이상
- 분석 실패 원인이 사용자에게 명확히 표시되는 비율 100%
- 사용자가 상위 개선 항목을 이해하고 실행할 수 있는 비율 향상
