# v0.5 AI 인사이트

## 사용자 흐름

1. URL 분석을 완료합니다.
2. `AI 인사이트`에서 회사 소개를 입력합니다.
3. 필요하면 회사 목적과 주요 고객을 추가합니다.
4. Enter 또는 `3개 관점 AI 조언 생성`을 누릅니다.
5. 마케터, 경영자, 운영자 관점의 조언을 탭으로 확인합니다.

회사 소개는 필수이며 입력 중에는 API를 호출하지 않습니다. 사용자가 Enter를 누르거나 생성 버튼을 선택했을 때만 세 관점을 동시에 요청합니다.

## Gemini 연결

- 브라우저 설정에 저장한 Gemini API 키를 `/api/insight` 요청에 포함합니다.
- 배포 환경에서는 서버의 `GEMINI_API_KEY`도 사용할 수 있습니다.
- 회사 소개와 분석 결과 일부가 조언 생성을 위해 Gemini에 전달됩니다.
- 페르소나별 실패 상태와 재시도 동작을 제공합니다.

## 세 가지 관점

- 마케터: 검색 유입, 콘텐츠, 전환 관점
- 경영자: 사업 가치, 경쟁력, 우선순위 관점
- 운영자: 실행 난이도, 유지관리, 실무 작업 관점
