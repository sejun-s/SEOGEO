# v0.6 점수 모델 결정 기록

## 제품 정의

화면의 숫자는 검색엔진 공식 점수나 순위 예측치가 아니라 `SEOGEO 자체 준비도 지수`다. 실제 Google·네이버 색인, 검색 노출, 클릭 또는 AI 인용을 보장하지 않는다.

## 핵심 원칙

- Gemini는 설명과 조언에만 사용하고 숫자는 규칙 엔진이 결정한다.
- 확인할 수 없는 신호에 중립 기본점수를 부여하지 않는다.
- 검색 자격에 실패하면 SEO 기술 준비도와 자체 준비도 지수를 25점으로 제한한다.
- GPTBot 학습 정책은 ChatGPT 검색 접근 점수에서 제외한다.
- 예상 점수 상승 대신 영향도 높음·중간·낮음을 표시한다.
- 점수는 실제 재검사 후에만 변경한다.
- 대표 페이지 검사와 사이트 전체 Health를 구분한다.

## 자체 준비도 지수 v0.6-r1

사이트 전체 크롤링이 있는 일반 분석은 다음 차원을 사용한다.

- SEO 기술 준비도: 55%
- AI 인용 준비도: 25%
- 네이버 검색 준비도: 10%
- 사이트 전체 Health: 10%

검색 자격 게이트가 실패하면 최종 지수는 최대 25점이다. 하위 점수는 원인을 설명하기 위한 진단 지표이며 공식 검색엔진 가중치가 아니다.

## 네이버 검색 준비도

자동 측정 범위:

- Yeti 또는 일반 robots 정책의 전체 차단 여부
- meta robots noindex 여부
- Title 40자·Description 80자 이내 권장 범위
- Sitemap 발견 여부
- canonical 존재 여부

자동 측정 불가 범위:

- 네이버의 실제 수집·색인 여부
- 서치어드바이저 등록·소유확인·Sitemap 제출 완료 여부
- 실제 노출·클릭 및 검색어 성과

자동 측정 불가 항목은 감점 근거로 사용하지 않고 서치어드바이저 확인 과제로 안내한다.

## 외부 배포 전 검증 조건

- 규칙별 공식 출처와 자체 휴리스틱 구분
- 정상·차단·부분 차단 robots 테스트
- 대표 페이지와 사이트 전체 결과의 일관성 테스트
- 최소 30개 사이트에 대한 전문가 블라인드 검토
- Google Search Console·네이버 서치어드바이저 실제 데이터와 방향성 비교
- 거짓 양호와 거짓 경고 사례 기록 및 임계값 조정
