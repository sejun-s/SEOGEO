## 3. URL 분석 메뉴 정의

### 3.1 SEO 기반 품질

| 항목 | 정의 |
|---|---|
| 목적 | 검색엔진이 홈페이지를 접근·수집·색인하고 HTML 구조를 이해할 수 있는지 평가 |
| 주요 진단 | 검색 자격, 기술·HTML 구조, 검색봇 접근, Canonical, Title, Description, heading, Schema, Sitemap, 내부 링크, 사이트 크롤링 |
| 점수 성격 | 공개 HTML·HTTP·robots.txt의 실측 신호를 사용하는 자체 준비도 지수. 검색 순위를 의미하지 않음 |
| 솔루션 | HTML, meta, canonical, robots.txt, JSON-LD 등 복사 가능한 구조 수정 코드 제공 |
| 사이트 전체 분석 | Sitemap과 내부 링크를 따라 최대 범위 내 페이지를 탐색해 오류, 중복 Title·Description, 누락 신호를 집계 |
| 완료 기준 | 수정 후 동일 URL을 재분석하여 해당 규칙이 통과되고 사이트 Health 변화가 확인됨 |

### 3.2 GEO 인용 준비도

| 항목 | 정의 |
|---|---|
| 목적 | AI 검색 서비스가 페이지 내용을 발견하고, 이해하고, 답변 근거로 추출하기 쉬운 상태인지 평가 |
| 주요 진단 | OAI-SearchBot 등 접근성, 콘텐츠 계층, 질문형 제목, Answer-first 구조, 출처·수치, 저자·날짜, 엔티티·sameAs |
| 점수 성격 | 실제 AI 인용률이 아니라 정적 페이지의 인용 준비 상태를 나타내는 자체 지수 |
| 솔루션 | 질문-답변형 콘텐츠 구조, 검증된 수치·출처 표기, 저자·업데이트 정보, 엔티티 연결 템플릿 제공 |
| 연계 | 실제 인용 여부가 필요하면 GEO 모니터링으로 이동 |
| 완료 기준 | 콘텐츠 수정 후 재분석으로 추출성·근거 품질·엔티티 점수 변화를 확인하고, 필요 시 실제 엔진 측정 |

### 3.3 네이버 노출 기반

| 항목 | 정의 |
|---|---|
| 목적 | 네이버 검색로봇 수집과 웹문서 반영을 위한 기본 기술 준비 상태 점검 |
| 주요 진단 | Yeti 접근, noindex, Title·Description 존재 및 고유성, Sitemap·RSS 발견 |
| 점수 성격 | 네이버 검색 노출·순위 보장 점수가 아닌 정적 준비도 지수 |
| 솔루션 | Yeti 접근 규칙, 메타데이터, Sitemap·RSS 생성·제출 안내 |
| 외부 확인 | 실제 수집·색인·유입은 네이버 서치어드바이저 계정에서 별도 검증 필요 |
| 완료 기준 | 정적 규칙 통과 후 서치어드바이저에서 소유 확인, 피드 제출, 수집·색인 상태 확인 |

## 12. 화면 노출 규칙

1. 분석 이력이 없으면 랜딩 페이지와 URL 입력창을 표시한다.
2. URL 분석이 완료되면 `URL 분석`, `GA4 분석`, `AI 인사이트` 메뉴를 표시한다.
3. Shopify가 감지된 경우에만 `Shopify AI` 메뉴를 추가한다.
4. URL 분석 메뉴를 선택했을 때만 `SEO 기반 품질`, `GEO 인용 준비도`, `네이버 노출 기반` 서브 메뉴를 표시한다.
5. 보고서 기능은 분석 결과가 존재할 때 표시한다.
6. 비교 분석은 분석 기록에서 2개 이상 결과를 선택해야 실행한다.
7. GEO 모니터링은 URL 분석과 독립적으로 접근할 수 있으나 실제 측정에는 API 연결이 필요하다.
8. AI 인사이트는 회사 소개가 입력되어야 활성화된다.

| 사이트 내부 페이지 크롤링 | SEO 기반 품질 | Health 및 중복·오류 진단 |
| 콘텐츠 구조·근거 신호 | GEO 인용 준비도 | 실제 인용 결과가 아닌 준비 상태 |
| 네이버 정적 준비 신호 | 네이버 노출 기반 | 실제 색인은 서치어드바이저 확인 |
| AI 실제 응답·인용 | GEO 모니터링 | API 비용과 비결정성 존재 |
| 사용자 입력 회사 정보 기반 조언 | AI 인사이트 | 점수와 분리된 참고 콘텐츠 |
| 방문·전환 실데이터 | GA4 | 현재는 설치 진단 중심, 계정 연동 확장 필요 |
