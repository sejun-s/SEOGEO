# SEOGEO v0.4 HTML 보고서

## 제공 기능

- 현재 분석 결과를 독립 실행형 HTML 보고서로 생성
- 새 브라우저 탭에서 보고서 미리보기
- 브라우저 인쇄 기능을 이용한 PDF 저장
- `.html` 파일 다운로드
- 데스크톱·모바일 보고서 레이아웃

## 보고서 구성

1. 사이트명, URL, 분석일과 점수 모델
2. SEO 기반 점수와 AI 인용 준비도
3. Technical SEO, ChatGPT Search, GEO, E-E-A-T, Schema.org, Bing/AEO 점수
4. 우선순위별 문제, 현재 상태, 해결 방법, 예상 점수 효과
5. 적용 가능한 HTML·JSON-LD·robots.txt 코드
6. 현재 강점
7. 사이트 전체 Health Score와 크롤링 범위
8. 점수 및 데이터 범위 면책 안내

## 안전성과 호환성

- 사이트 제목과 분석 텍스트는 HTML 특수문자를 이스케이프 처리합니다.
- 보고서는 외부 서버로 데이터를 전송하지 않고 현재 브라우저에서 생성합니다.
- 기존 LocalStorage 분석 이력 구조와 점수 계산 로직을 변경하지 않습니다.

## 인사이트 입력 개선

사이트 소개와 타겟 고객은 입력 중에는 초안 상태만 변경합니다. `Enter`를 눌렀을 때 저장된 사이트 정보와 AI 인사이트 캐시에 반영합니다. 사이트 소개에서 줄바꿈이 필요하면 `Shift+Enter`를 사용합니다.
