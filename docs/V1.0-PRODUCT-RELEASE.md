# SEOGEO v1.0 — 홈페이지 SEO·GEO 제품 기준

## 제품 정의

SEOGEO v1.0은 기업·SaaS·기관·전문 서비스 홈페이지를 대상으로 검색엔진과 AI 검색이 사이트를 이해하기 위한 기반을 진단하고, 실제 수정 액션과 재검증 흐름을 제공한다.

쇼핑몰 상품 SEO·GEO는 v1.x 이후 별도 제품 모드로 개발한다.

## 핵심 분석 영역

1. **SEO 기반 품질**: 수집·색인·HTML 구조·내부 링크·Schema·사이트 오류
2. **AI 검색 가시성**: AI 검색봇 접근·브랜드 엔티티·인용 구조·콘텐츠 신뢰 신호
3. **네이버 노출 기반**: Yeti·메타 정보·Sitemap·Canonical·서치어드바이저 확인 절차

각 영역은 독립 점수, 최우선 액션, 세부 지표, 개선 체크리스트를 가진다. 측정할 수 없는 항목은 0점이 아니라 미측정으로 처리한다.

## GEO 모니터링 등급

- **검색·출처 측정**: Perplexity
- **검색 기반 측정**: OpenAI Responses API Web Search, Gemini Search Grounding
- **참고 응답**: Claude 일반 생성 API
- **베타**: 네이버 HyperCLOVA X. 네이버 통합검색 노출과 동일한 지표로 표현하지 않는다.

모든 결과는 질문, 엔진, 실행 시각, 응답 미리보기, 출처 URL, 오류 상태를 보존한다. API 오류나 키 미설정은 0%로 집계하지 않는다.

## 비용·안전 기준

- 실행량 = 질문 수 × 엔진 수 × 반복 횟수
- 1회 요청당 질문 최대 30개, 엔진 최대 5개, 반복 1·3·5회
- 개발 서버 GEO 요청은 IP별 분당 5회 제한
- 프로덕션에서는 사용자 인증, 요금제별 크레딧, 조직별 데이터 분리, 영속 사용량 원장을 추가해야 한다.
- API 키는 서버 환경변수로만 관리하며 응답과 로그에 노출하지 않는다.

## 판매 전 필수 외부 조건

코드 버전 1.0과 실제 상용 출시 승인은 별개다. 아래 조건을 만족해야 유료 판매를 시작한다.

- 결제·환불 정책과 이용약관
- 개인정보처리방침
- 검색 API 결과 저장에 대한 공급자 약관 검토
- 최소 5개 유료 파일럿과 실제 수정 후 재분석
- 고객별 데이터베이스, 인증, 백업, 장애 모니터링
- API 원가가 매출의 20% 이하인지 확인

## v1.0 완료 기준

- 세 메뉴에서 서로 다른 점수·최우선 액션·진단·개선 액션 제공
- 점수 근거와 측정 신뢰도 표시
- 영향 URL과 수정 코드 제공
- 개선 전후 재분석 가능
- GEO 오류와 미언급 구분
- 린트·테스트·프로덕션 빌드 통과
